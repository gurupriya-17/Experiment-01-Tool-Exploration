# Experiment 1: Study and Explore Forensic Tools

## Aim
To study and explore digital forensic tools and understand their uses in digital evidence investigation.

## Tools Used
1. Autopsy
2. Guymager
3. USBDeview
4. The Sleuth Kit

## Description

### 1. Autopsy
Autopsy is a graphical digital forensic tool used to analyze disk images, files, metadata, and available deleted-file records.

### 2. Guymager
Guymager is a Linux-based forensic imaging tool used to create forensic copies of storage devices.

### 3. USBDeview
USBDeview is a Windows utility used to examine recorded information about USB devices connected to the system.

### 4. The Sleuth Kit
The Sleuth Kit is a command-line toolkit used to analyze file systems and examine digital evidence.

## Procedure
1. Open and explore the available forensic tools.
2. Observe the main interface and important features of each tool.
3. Identify the purpose of each tool in digital forensic investigation.
4. Capture screenshots of the actual tool interfaces.
5. Record observations and document the learning outcomes.

## Observations
- Autopsy provides a graphical interface for forensic analysis.
- Guymager supports forensic disk acquisition.
- USBDeview displays recorded USB device information.
- The Sleuth Kit provides command-line utilities for file-system analysis.

## Result
The forensic tools were studied to understand their features and applications in digital forensic investigation.
